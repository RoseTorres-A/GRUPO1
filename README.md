# Registro de Envases Retornables para Mercados - ODS 12

## Descripción del proyecto

El proyecto consiste en el desarrollo de una plataforma para el control de préstamo y devolución de envases reutilizables en comercios y mercados de abastos.

La plataforma permitirá registrar y gestionar información relacionada con:

- Comerciantes.
- Envases retornables prestados.
- Devoluciones de envases.
- Vales asociados al préstamo y devolución de envases.

El sistema no administra penalizaciones pecuniarias.

## Público objetivo

La solución está orientada principalmente a:

- Mercados de abastos.
- Municipalidades.
- Comerciantes que participan en el sistema de préstamo y devolución de envases reutilizables.

## Objetivo

Desarrollar una solución de software que permita llevar un mejor control de los envases reutilizables que son entregados y posteriormente devueltos, facilitando el registro y seguimiento de estas operaciones.

## ODS relacionado

El proyecto se relaciona con el **Objetivo de Desarrollo Sostenible (ODS) 12: Producción y Consumo Responsables**, debido a su enfoque en el uso y reutilización de envases, buscando contribuir a una gestión más responsable de los recursos y a la reducción del uso innecesario de envases descartables.
